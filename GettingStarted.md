# Getting Started
For setup first you need the following things:
- Flutter Version 3.27.1
- IDE like Android Studio or VS Code with Flutter Plugin installed.

## Steps to run App
1.⁠ ⁠Clone the repository with Git

```git clone https://github.com/simonoppowa/Nutriq.git```

2.⁠ ⁠Get Dependencies

```flutter pub get```

3.⁠ ⁠Run Build Runner to generate files

```flutter pub run build_runner build```

4.⁠ ⁠Run App

```flutter run lib/main.dart```

## Running the Application

Nutriq currently supports Android and iOS.

### iOS
```bash
open -a Simulator
flutter run
```

### Android
```bash
flutter run -d android
```
